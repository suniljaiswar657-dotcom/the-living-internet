# THE LIVING INTERNET

A standalone, mobile-first personal digital universe prototype. This repository is independent and does not reuse or modify any other project.

## Features
- Futuristic black-and-silver interface with Poppins typography
- Responsive layout for Android/mobile and desktop
- Three starter worlds: Learning Lab, Idea Forge, and Future Studio
- Create, open, and delete worlds
- Browser-local persistence using localStorage
- JSON backup export and import
- No backend, account, or API key required

## Run locally
Open `index.html` in a modern browser. An internet connection is needed to load Poppins from Google Fonts; the app itself runs without a backend.

## Deploy free with GitHub Pages
1. Open this repository's **Settings → Pages**.
2. Under Build and deployment, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site.

## Data and privacy
Worlds are saved in the current browser on the current device. They are not synced to a server. Clearing browser site data may erase them, so export a JSON backup before changing devices or clearing data.

## Current scope
This is prototype 0.1. It is a static web app, not an AI-powered or multi-user platform yet.
